WARBOARD v31.1 — VISUAL STATE + TRANSPARENT BATTLE LOG
TRADITIONAL COMPLETION PASS 1 OF 5

BASELINE
Apply over the working v31 Dual Resolution Mode Alpha.

DESIGN RULE
XCOM mode automates procedure, not information.
Traditional mode exposes procedure, but uses the same audit data.

Every dice roll made through DiceRoller is now copied into a persistent
BATTLE LOG even when XCOM mode hides the routine dice UI.

BATTLE LOG
New LOG button in the top command bar.

The log records:
- every DiceRoller result, including hidden XCOM rolls;
- attack summaries plus detailed hit / wound / save / damage audit data;
- Battle-shock tests;
- player-selected casualties;
- XCOM Reanimation results;
- live objective-control changes.

Attack audit entries include:
- weapon;
- number of attacks;
- hit target and hit modifier;
- actual hit rolls;
- wound Strength vs Toughness and required value;
- actual wound rolls;
- save type / target / AP;
- actual save rolls;
- damage values;
- wounds and models lost;
- rule summary/modifier text already generated by the attack engine.

The log is shared by XCOM and Traditional mode.

BATTLE-SHOCK VISUAL LANGUAGE
Battle-shocked units now receive an ICE-BLUE pulsing aura around every living
model's base.

The miniature's own paint/model material is not recoloured.
The status is therefore obvious without obscuring the model.

The effect:
- appears immediately when SetBattleShocked(true) resolves;
- applies to an Attached Leader with its Bodyguard;
- survives normal selection highlighting;
- disappears when Battle-shock ends;
- hides correctly with staged/reserve presentation.

OBJECTIVE CONTROL COLOURS
Physical objective markers now update live:
- controlled objective -> controlling faction colour;
- contested objective -> pulsing warning colour;
- uncontrolled objective -> neutral grey.

Objective text also takes on the controlling faction colour.
GameController refreshes objective state roughly every 0.12 seconds, so moving
onto/off an objective changes its appearance without waiting for a phase end.

Objective-control changes are also written to the Battle Log.

SMALL UI FIX
The existing Mission top-bar toggle accidentally switched itself off as soon as
it was opened. v31.1 corrects that while adding the LOG panel.
