WARBOARD v31.4 — TRADITIONAL FACTION / RANDOM FIREWALL
TRADITIONAL COMPLETION PASS 4 OF 5

BASELINE
Apply over the working v31.3 Traditional State Controls build.

CORE PHILOSOPHY
Traditional is now explicitly treated as a DIGITAL TABLETOP.

Warboard can:
- maintain turns/phases
- track CP and clicked Stratagem use
- apply persistent non-random status effects
- track movement allowances after the player supplies a final value
- show legal ranges / board state / coherency / objectives
- provide manual wound and restoration tools

Warboard must NOT:
- generate a tabletop roll for the player
- decide whether a physical roll succeeded
- automatically offer a reroll because it saw a failed die
- silently apply random faction-rule healing/movement/damage

FIRST-TURN ROLL-OFF
Traditional no longer auto-rolls the first-turn roll-off.
- 3D tray opens with 2 D6 suggested.
- Players roll one each and resolve ties/rerolls themselves.
- Warboard only asks which player won.
- XCOM still resolves the roll-off automatically.

GENERIC MANUAL RESULT CONTROL
v31.4 adds a reusable Traditional "final value" prompt.

This is now used for random faction movement such as:
- Opportunity Seized — D6+1
- Fade Back — D6+1
- Lethal Surge — D6+1
- Lethal Intent — D6+1

The relevant resource/effect is still clicked and tracked.
The player rolls in the 3D tray and enters only the final movement value.
Warboard then provides the movement interaction.

COMMAND RE-ROLL
Traditional Command Re-roll no longer arms a hidden automatic reroll.

When the player chooses the Stratagem:
- 1 CP is spent;
- the 3D tray is made available;
- the player rerolls whatever die the tabletop rules permit;
- Warboard does not choose the die, generate the replacement result, or judge
  whether the reroll was legal/successful.

XCOM retains its automatic/contextual Command Re-roll flow.

MANUAL RESTORE EDITOR
Traditional now has RESTORE EDIT beside WOUND EDIT.

Select a surviving unit/model and RESTORE EDIT can:
- cycle destroyed models belonging to that unit;
- RETURN 1W;
- RETURN FULL.

This is deliberately a free tabletop-state editor.
Warboard does not police whether a rule permits the restoration.

FACTION / DATASHEET RANDOM RESTORATION
Traditional paths are now manual for:

WORD OF THE PHOENIX
- player resolves the D6 and any D3+1 roll;
- RESTORE EDIT chooses which models return.

TEARS OF ISHA
- destroyed-model return is handled with RESTORE EDIT;
- D3 healing is rolled by the player and applied with WOUND EDIT.

RESURRECTION ORB
- player rolls the D6;
- WOUND EDIT / RESTORE EDIT applies the result manually;
- the Orb's used state is still tracked.

PROTOCOL OF THE UNDYING LEGIONS
- protected against automatic Traditional Reanimation if this reaction path is
  invoked;
- CP/effect can still be selected;
- player rolls and applies restoration manually.

RANDOM ATTACK / DAMAGE
Traditional attacks remain declaration-only from v31.2/v31.3.
A/D expressions are shown in the weapon declaration, and all random attack or
damage rolls stay entirely in the player's 3D tray.

NO CHANGE TO XCOM
XCOM continues to use:
- InteractiveAttackController
- automatic dice resolution
- automatic faction/random mechanics
- transparent Battle Log auditing
