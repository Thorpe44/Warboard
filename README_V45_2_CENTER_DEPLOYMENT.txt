WARBOARD v45.2 - CENTER DEPLOYMENT PANEL

Purpose
=======
Centers the deployment UI box horizontally on screen.

This targets the deployment panel method in:
Assets\Scripts\Core\GameController.UI.cs

It finds the deployment UI method using the on-screen label:
    DEPLOYMENT ORDER
and then recenters that method's main Rect.

Install
=======
1. Extract this ZIP over the main Warboard project folder.
2. Run:
   INSTALL_WARBOARD_V45_2_CENTER_DEPLOYMENT.bat
3. Return to Unity and let it compile.

Backup
======
Original file backup is written to:
Library\WarboardBackups\V45_2CenteredDeployment
